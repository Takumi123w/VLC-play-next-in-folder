# VLC play next in folder
Not lua since not work in my system for not reason

Make sure vlc installed
- sudo pacman -S vlc
or
- sudo apt install vlc

Clone this git
- git clone https://github.com/Takumi123w/VLC-play-next-in-folder.git
- cd VLC-play-next-in-folder
- gcc vlc_next_in_folder.c -o vlc_next_in_folder
- cp vlc_next_in_folder ~/.local/bin
- chmod +x ~/.local/bin/vlc_next_in_folder

Or
- download in release page github
- copy and paste into ~/.local/bin/vlc_next_in_folder
- then open properties and checklist permission to allow execute as program like image in bellow
